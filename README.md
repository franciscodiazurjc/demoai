# demoai

Demo de IA para Dirección de Proyectos, centrada en prototipos HTML del caso Atocha.

## ¿Qué hay en este workspace?

- `index.html`: versión principal actual de la demo.
- `atocha-restauración-copilot.v*.html`: iteraciones de la demo de restauración (versiones generadas/refinadas con Copilot).
- `atocha-restauración.v*.html`: variantes históricas de restauración.
- `atocha360-v*.html`: variantes de la demo Atocha 360 (EDT/seguimiento).
- `atocha-restauración.PROMPTS.v4.html`: versión de apoyo con prompts.
- `qr.png` y `qr-v4.png`: recursos gráficos de QR.

## Cómo usarlo localmente

1. Abrir `index.html` directamente en navegador, o
2. Servir la carpeta con un servidor estático (por ejemplo `python -m http.server`) y abrir la URL local.
